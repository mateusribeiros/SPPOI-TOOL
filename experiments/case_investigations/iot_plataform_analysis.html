1. Sumário

A integração entre os sistemas FIWARE Orion Context Broker, FIWARE IoT Agent for LightweightM2M (LWM2M) e FIWARE Cygnus - Context Data Persistence é baseada em contratos de dados e semântica de comunicação bem definidos. No entanto, existem riscos relacionados à compatibilidade semântica e à sincronização do fluxo.

2. Análise Arquitetônica

A topologia da integração é baseada em um estilo de comunicação Publish-Subscribe via Context Broker, onde o FIWARE IoT Agent for LightweightM2M (LWM2M) envia dados para o FIWARE Orion Context Broker, que por sua vez notifica os sistemas interessados.

Os contratos de dados são baseados em schemas de dados JSON e NGSI, e a consistência semântica é garantida pela utilização de mecanismos de transformação de dados.

A confiabilidade operacional da integração é garantida pela utilização de mecanismos de sincronização do fluxo, como o throttling, e pela implementação de mecanismos de detecção e propagação de falhas.

A governança de contratos e a escalabilidade da integração são garantidas pela utilização de mecanismos de padronização de contratos de dados e pela implementação de mecanismos de escalabilidade.

3. Riscos Críticos de Integração e Interoperabilidade

Risco 1: Risco de Incompatibilidade Semântica entre Contratos de Dados

  • Classe de falha: Falha de Compatibilidade Semântica
  • Elementos afetados: FIWARE Orion Context Broker, FIWARE IoT Agent for LightweightM2M (LWM2M), Orion Context API - NGSI-v2, IoT Agent Device Management API
  • Evidência do cadastro: Evidências de contratos de dados JSON e NGSI, como os encontrados nas interfaces Orion Context API - NGSI-v2 e IoT Agent Device Management API, que utilizam formatos de dados JSON e NGSI, respectivamente.
  • Decisão arquitetural ou suposição implícita: Utilização de contratos de dados bem definidos, como os especificados nas interfaces Orion Context API - NGSI-v2 e IoT Agent Device Management API.
  • Mecanismo causal: Falta de governança de versionamento claro para os contratos de dados, o que pode levar a incompatibilidades semânticas entre as diferentes versões dos contratos de dados.
  • Manifestação da falha: Problemas de compatibilidade semântica entre as diferentes versões dos contratos de dados, o que pode afetar a entrega de dados e a consistência semântica.
  • Impacto na interoperabilidade: Problemas de entrega de dados e de consistência semântica, o que pode afetar a interoperabilidade entre os sistemas FIWARE Orion Context Broker, FIWARE IoT Agent for LightweightM2M (LWM2M) e FIWARE Cygnus - Context Data Persistence.
  • Consequências operacionais: Perda de dados e problemas de entrega de dados, o que pode afetar a operação dos sistemas e a tomada de decisões baseada nos dados.

Risco 2: Risco de Falha na Sincronização do Fluxo de Dados

  • Classe de falha: Falha de Sincronização do Fluxo
  • Elementos afetados: FIWARE Orion Context Broker, FIWARE IoT Agent for LightweightM2M (LWM2M), Orion Context API - NGSI-v2, IoT Agent Device Management API, Cygnus HTTP Sink (recebe notificações do Orion)
  • Evidência do cadastro: Evidências de mecanismos de sincronização do fluxo, como o throttling, nas interfaces Orion Context API - NGSI-v2 e Cygnus HTTP Sink (recebe notificações do Orion).
  • Decisão arquitetural ou suposição implícita: Utilização de mecanismos de sincronização do fluxo, como o throttling, para garantir a entrega de dados e a consistência semântica.
  • Mecanismo causal: Falta de política de retries clara para os mecanismos de sincronização do fluxo, o que pode levar a falhas na sincronização do fluxo de dados.
  • Manifestação da falha: Problemas de entrega de dados e de consistência semântica, o que pode afetar a operação dos sistemas e a tomada de decisões baseada nos dados.
  • Impacto na interoperabilidade: Problemas de entrega de dados e de consistência semântica, o que pode afetar a interoperabilidade entre os sistemas FIWARE Orion Context Broker, FIWARE IoT Agent for LightweightM2M (LWM2M) e FIWARE Cygnus - Context Data Persistence.
  • Consequências operacionais: Perda de dados e problemas de entrega de dados, o que pode afetar a operação dos sistemas e a tomada de decisões baseada nos dados.
